Escrita Front-END

Linguagens de programação Front-END, é a escrita de código do que aparece na tela do usuário. Isso inclui textos, imagens, vídeos, etc.

Estrutura

Simplificando, a estrutura do código é separada em:
  • !DOCTYPE
    • usado para indicar que o arquivo criado é em HTML;
  • Tag's < > são elementos que definem qual a função
  • <html> inicio do código html;
  • </html> para fechamento do html;
  • <head> é a parte onde é definido as configurações da sua página;
  • <body> literalmente como a tradução, é o corpo da sua página. Dentro dela vai:
    • <header> cabeçalho da página;
    • <main> conteúdo;
    • <footer> rodapé;
  • <script>Aqui é associado todo o funcionamento da página do tipo back-END

Algumas Tag's

TAG FUNÇÃO
<> Abertura de tag
</> fechamento de tag
<html> Começo do código
<head> configuração do código
<link> Colocar links de fonte de emotes, bibliotecas para CSS etc
<meta> regras que definem como o conteúdo será lido pelo navegador
<body> Corpo da página
<header> Cabeçalho da página
<main> Parte do "meio" da página
<footer> rodapé
<img> tag para inserir imagens
<video> usado para inserir arquivos de vídeo
<a> âncora. Usado pra criar textos clickáveis com links
<script> configuração back-end da página
<h1>...<hN> hierarquia, importância de texto
<p> abre um novo parágrafo
<div> abre uma divisória no código
<ul> abre uma lista com tópicos. "Unordered List"
<li> item da lista "List Item"

"Sub-tag"

class

A palavra "class" vai dentro de uma tag para identifica-la. Essa ferramenta pode ser usada em comando de CSS para estilização.

Exemplo:

<div class="texto1">

No código CSS:

.class="texto1"{

color: red;

}

isso quer dizer que a classe da div vai ser inteira modificada com a cor do texto de vermelho

id

O "id" é a sub-tag de identidade, com quase a mesma função de "class". A diferença é que a classe pode ser aplicada a mais de uma tag,

Já a identidade é única de uma tag

src

SRC significa "Source", no caso do código pode ser interpretado como "fonte" ou "origem"

Ela também vai dentro da tag de abertura e é usada para buscar um item como arquivos de mídia

Exemplo:

Dentro de uma pasta

<img src="imagem1.jpg">

Direto da internet

<img src="https://i.pinimg.com/originals/2a/2f/a0/2a2fa0db3179d4b4ec39d1a8a1eeda7d.jpg?nii=t">

Dentro de várias pastas

src="imagem/imagensExemplo/foto1234.jpg"
